# PocketSmart AI

PocketSmart AI is a smart budget and recommendation assistant.

It helps users generate budget-friendly recommendations for:

- Home Interior
- Party Planning
- Jewelry

## Technologies

- Python
- FastAPI
- Jinja2
- SQLite
- SQLAlchemy
- HTML
- CSS
- JavaScript
- Google Gemini AI
